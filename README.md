## 🚀 Selected Projects

### 💼 [Job Tools Platform](https://github.com/hannahro15/Job-tools-platform)

A job-hunting toolkit with an application tracker and notes, with authentication so each user's data stays private. It's designed for neurodivergent jobseekers. More features will be added over time, such as a dashboard of job application stats and a neurodivergent support page.

**Stack:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Clerk (authentication), PostgreSQL (Neon), Drizzle ORM, Vitest · [Live site](https://job-tools-platform.vercel.app)

### 🍽️ [Ready, Steady, Eat!](https://github.com/hannahro15/ready-steady-eat)

A full-stack e-commerce food shop with user accounts, product search and filtering, a shopping basket, and Stripe payments.

**Stack:** Python, Django, PostgreSQL, AWS S3, Stripe · [Live site](https://ready-steady-eat-8febfd678f9f.herokuapp.com/)

### 🎼 [Music Theory App](https://github.com/hannahro15/music-theory-app)

An interactive music theory learning app. Explore scales, intervals, 7th-chord arpeggios and a musical glossary on rendered sheet music, then test yourself with a classical music quiz.

**Stack:** React, React Router, React Bootstrap, VexFlow, Vite · [Live site](https://hannahro15.github.io/music-theory-app/)

### 🎢 [UK Rides Review Hub](https://github.com/hannahro15/Theme-park-ride-reviews-site)

A theme park ride review site where users can search rides by park and create, edit and delete their own reviews.

**Stack:** Python, Flask, MongoDB · [Live site](https://theme-park-reviews-website-f1f235eaa19d.herokuapp.com/)

## 🌍 Open Source

### Maintainer

🎻 **[Classical Music Themed Escape Room](https://github.com/hannahro15/classical-music-themed-escape-room)**: a free online escape room with music theory puzzles inspired by classical music. I started building it in November 2025 and decided to make it open source so others can get involved. React, Vite · [Live site](https://hannahro15.github.io/classical-music-themed-escape-room/)

🎵 **[Musical Match Saga](https://github.com/hannahro15/Musical-Match-Saga)**: my own idea for a music-themed match-3 puzzle game, combining Candy Crush and music, with level objectives, timed challenges, and limited moves and lives. I started it in December 2025 by building the game board and some basic logic from a YouTube tutorial, then developed the rest on my own with GitHub Copilot, including most of the game logic, the basic design and 20 levels, before making it open source in November 2026. It's accessible (keyboard navigation, ARIA roles, and reduced-motion support). I tested the game logic with Jest and code coverage. Tests and linting now run in GitHub Actions, and the site only deploys if they pass. HTML, CSS, JavaScript (ES modules), Jest, GitHub Actions · [Live site](https://hannahro15.github.io/Musical-Match-Saga/)

Contributions are welcome on both! Each one has a contributing guide and good first issues to get started:

- Escape Room: [contributing guide](https://github.com/hannahro15/classical-music-themed-escape-room/blob/main/CONTRIBUTING.md) · [good first issues](https://github.com/hannahro15/classical-music-themed-escape-room/contribute)
- Musical Match Saga: [contributing guide](https://github.com/hannahro15/Musical-Match-Saga/blob/main/CONTRIBUTING.md) · [good first issues](https://github.com/hannahro15/Musical-Match-Saga/contribute)
